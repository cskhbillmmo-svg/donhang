Thư mục này dùng để lưu ảnh logo cấp độ VIP.

Cách đặt tên file (BẮT BUỘC để code tự nhận):
  - vip1.png  (huy hiệu cấp 1)
  - vip2.png  (huy hiệu cấp 2)
  - vip3.png  (huy hiệu cấp 3)
  - vip4.png  (huy hiệu cấp 4)
  - vip5.png  (nếu có)
  ...

Định dạng khuyến nghị: PNG nền trong suốt, kích thước vuông (ví dụ 512x512).
Có thể dùng .jpg / .webp / .svg — nhưng phải đổi tên đúng vip{N}.

Sau khi copy ảnh vào đây, ảnh sẽ tự động hiển thị thay cho khối
"CLASSIC SIÊU VOUCHER 500K" ở màn hình Đơn hàng theo cấp VIP của tài khoản.
